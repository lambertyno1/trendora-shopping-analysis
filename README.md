# Shopping Customer Data Analysis – Excel Project

## Project Overview

This project analyzes customer shopping data using Microsoft Excel. The project involved data cleaning, Pivot Table analysis, and the presentation of key findings from the dataset.

## Objective

The objective of this project was to analyze customer shopping behavior and identify useful insights relating to purchases, customers, products, age groups, seasons, and payment methods.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Data Cleaning
- Excel Dashboard

## Data Preparation

The original shopping dataset was cleaned and organized before analysis. The cleaned dataset contains information relating to customer demographics, products, purchase amounts, locations, seasons, ratings, subscriptions, shipping types, payment methods, and discounts.

## Analysis Performed

The following areas were analyzed:

- Total purchase amount
- Average customer rating
- Number of unique customers
- Top-performing products
- Purchase amount by age group
- Purchases by season
- Payment methods used by customers

## Key Findings

- Total purchase amount: $164,202
- Average customer rating: 3.83
- Total unique customers: 2,761
- Dress recorded the highest purchase amount among the top five items, at $7,403.
- The 60–70 age group recorded the highest purchase amount, at $38,959.
- Fall recorded the highest share of purchases, at approximately 26.1%.
- Debit Card was the most frequently used payment method, at approximately 35.6%.

## Conclusion

The analysis provided useful insights into customer purchasing patterns, product performance, age-group spending, seasonal purchasing, and payment preferences. These insights can support business decisions relating to customers, products, and sales.
